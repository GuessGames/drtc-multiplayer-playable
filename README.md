# Death Road to Canada – Online Multiplayer

Play **Death Road to Canada** together online (RadminVPN, LAN or internet) instead of local co-op.
Everyone plays the same run in sync, each with their own keyboard, controller and mouse.

Every player needs their own copy of the game (Steam, Windows version) and the same mod version.

## Install
1. Download **[DRTC-Multiplayer-Setup.bat](https://github.com/GuessGames/drtc-multiplayer-playable/raw/main/DRTC-Multiplayer-Setup.bat)**.
2. Close the game, then double-click the file.
   It finds the game, installs the mod and opens the multiplayer launcher.
   (If Windows SmartScreen appears: *More info* → *Run anyway*.)

## Play together
1. Everyone joins the same RadminVPN network (or is on the same LAN).
2. Start the game → **MULTIPLAYER** → **RESTART IN MULTIPLAYER** (or the launcher's *1 window* button).
3. Host: **HOST A GAME → OPEN LOBBY**, share the green `26.x.x.x` address.
   Friends: **JOIN A GAME**, type that address → **CONNECT**.
4. The host presses **START GAME**.

F10 opens the multiplayer menu. Multiplayer uses its own save profile; normal saves are untouched.

## Update / uninstall
- Launcher → **Update mod from GitHub** (or run the setup file again).
- Launcher → **Uninstall mod** (Steam "Verify integrity of game files" also removes it).

## Problems
Logs are in the game folder (`mp_mod.log`). If a red *OUT OF SYNC* banner appears, send the logs of all players.
